# 1강 실습 화면

비전공자가 읽고 답을 고르는 학습지. ENERGY 1 / RHYTHM 2 / MOTION 1.

원문과 같은 한국어 문항을 화면의 중심에 놓습니다. 밝은 종이색, 짙은 본문색, 녹색 한 가지 강조색을 사용합니다. 강조색은 선택 상태와 이동 링크를 구분합니다. 큰 제목과 두 실습 사이의 짧은 원리 설명으로 읽는 순서를 만듭니다. 시스템 글꼴은 한글 가독성과 빠른 로딩을 위해 사용합니다. 장식 이미지, 추적 스크립트, 외부 글꼴, 계정 기능은 필요하지 않습니다.

좁은 화면에서도 한 열로 읽으며 라디오와 버튼은 키보드로 조작합니다. 선택·미선택·오답·정답·재시도 상태를 문장으로 알리고, 피드백은 보조 기술에 전달합니다. 페이지 자체에 사용자 응답을 저장하지 않습니다.
