# 네이버 블로그용 개별 파일

`lesson-01.txt`부터 `lesson-30.txt`까지 강의 하나당 파일 하나입니다. 첫 줄을 글 제목으로 쓰고 나머지를 본문에 복사하세요. 문단과 표의 모양은 네이버 편집기에서 확인해 주세요. 표는 일반 텍스트에서 셀 순서를 잃지 않도록 행마다 `|`로 구분했습니다.

이 파일들은 원문을 블로그용으로 정적으로 변환했습니다. 슬라이더나 자동 채점이 본문에 실행되는 것은 아닙니다. 1강 파일에는 별도 대화형 실습 페이지 링크가 포함되어 있습니다. 지금 게시 대상은 1강 한 편이며, 나머지 강의의 공개 게시를 뜻하지 않습니다.

2026-11-11에 [1강을 네이버 블로그에 공개](https://blog.naver.com/ajitta/224472328521)했습니다. 처음에는 전체 본문을 정적으로 옮겼고, 사용자 피드백에 따라 아래 요약 형식으로 수정했습니다. 2–30강은 게시하지 않았습니다.

1강 게시본을 **강의 핵심·요약 + 1강 학습 페이지 직접 링크** 형식으로 수정했습니다. 해당 게시용 요약은 `lesson-01-summary.html`이며, JavaScript를 실행하는 임베드 코드가 아니라 편집기에 서식 있는 글로 붙여넣기 위한 원고입니다. 일반 텍스트 원고는 `naver-summary-01.txt`입니다. `lesson-01.txt`는 앞서 만든 전체 강의의 정적 복사본으로 구분해 보관합니다.

원문·편집 차이는 [출처 안내](../PROVENANCE.md), 전체 강의는 [목차](../README.md)를 참고하세요.

## 1강 편집형 요약

1강의 공개 게시본은 `ChatGPT Thinking → AI 기본원리` 카테고리에 있습니다. 짧은 제목, 새로 만든 표지, 19px 본문, 핵심 세 가지, 원본 도식, 네이버 인용구, 1강 직접 링크로 구성했습니다. 표지와 블로그용 도식 PNG는 `assets/`에 보관합니다.

`lesson-01-summary.html`은 편집 원고입니다. 네이버에서 동일하게 보이려면 이미지는 사진으로 첨부하고 마지막 요약 문장은 네이버 인용구 서식을 적용해야 합니다. HTML의 여백과 레이아웃이 그대로 유지된다고 보장하지 않습니다. 본문 전체를 이미지로 바꾸지는 않았습니다.

## 매거진판 (2026-11-11 발행, 현재 게시본)

글 제목을 "ChatGPT는 다음 단어만 맞히는데, 어떻게 추론까지 할까?"로 바꾸고 매거진형으로 다시 짰습니다. 원문에서 고른 핵심 문장을 따옴표 인용구로 맨 앞에 두고, 리드 문단·소제목·마무리 문장은 마루부리, 본문은 나눔고딕입니다. 소제목에는 번호를 붙이지 않고 짧은 구분선으로 단락을 나눕니다. 소제목은 19px로, 360px 휴대폰에서 한 줄에 들어가는 길이로 씁니다. 본문은 양끝 정렬이고 빈 줄은 본문 문단 사이와 소제목 다음에만 둡니다. 예문은 버티컬 라인 인용구(굵게)입니다. 인용구 안에서는 편집기가 서체 변경을 지원하지 않아 예문은 나눔바른고딕으로 보입니다. 원고는 `lesson-01-summary.html`(맨 위 주석에 편집기 적용 규칙)과 `naver-summary-01.txt`입니다.

썸네일은 `assets/thumb-lesson-01.png`이며 글 맨 끝에 작게 넣고 대표 사진으로 지정했습니다. 30강 공통 틀로 `tools/thumbnail.py`가 만듭니다. 마루부리 글꼴은 `tools/fonts/`에 두며 저장소에는 올리지 않습니다(`.gitignore`).

이전 판(아티클판, 실습 보완판)은 git 기록에 남아 있습니다.
